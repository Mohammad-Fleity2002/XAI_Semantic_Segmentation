# XAI for Semantic Segmentation

This project presents an evaluation of Explainable AI (XAI) methods applied to **semantic segmentation**, based on the research paper:  
**"Extending CAM-based XAI Methods for Remote Sensing Imagery Segmentation"**  
📄 [Read the paper](https://sciforum.net/manuscripts/18027/manuscript.pdf)  
📁 [Original GitHub Repository](https://github.com/geoaigroup/GEOAI-ECRS2023/tree/main/Extending%20CAM-based%20XAI%20methods%20for%20Remote%20Sensing%20Imagery%20Segmentation)
